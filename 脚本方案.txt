## 一、账号定位与8大方向

| # | 方向 | 核心内容 | 可量化指标 | 适配屯军营 |
|---|------|---------|-----------|-----------|
| A | **村务日记型** | 每天工作实拍：开会、走访、修路、调解纠纷 | 粉丝量、完播率、评论"办事"关键词占比 | ⭐⭐⭐ |
| B | **乡村振兴纪实型** | 村庄变化对比：改造前vs改造后、项目进展 | 播放量、收藏量、政务媒体转发次数 | ⭐⭐⭐ |
| C | **农业产业带货型** | 农产品展示→挂车销售 | GMV、转化率、复购率 | ⭐⭐ |
| D | **基层政策解读型** | 用大白话解释惠农政策、宅基地、医保 | 粉丝增长、评论提问量、二次传播率 | ⭐⭐⭐ |
| E | **村支书Vlog型** | "村支书的一天"人格化内容 | 粉丝粘性、评论情感正负比 | ⭐⭐⭐ |
| F | **乡村文化IP型** | 村名由来、军屯历史、延庆民俗 | 完播率、文旅部门关注、媒体报道 | ⭐⭐⭐ |
| G | **矛盾调解真人秀** | 真实邻里纠纷调解（脱敏处理） | 评论互动率、争议话题出圈概率 | ⭐⭐ |
| H | **村支书带你看延庆** | 以屯军营为基地辐射延庆文旅资源 | 文旅局合作机会、旅游转化 | ⭐⭐ |

**推荐组合策略：** 主攻 E+F（人格化Vlog + 文化IP），辅助 D（政策解读引流），阶段性测试 C（带货）。

## 二、账号启动逻辑框架

```
┌─────────────────────────────────────────┐
│ 第1层：定位层（WHO + WHAT）              │
│ • 王健是谁？→ 延庆屯军营村的村支书       │
│ • 账号调性？→ 真实/接地气/有温度/能办事  │
│ • 对标账号？→ 找3个已成功的同类型账号    │
├─────────────────────────────────────────┤
│ 第2层：内容层（CONTENT PILLARS）         │
│ • 3-4个内容支柱：日常工作 + 政策解读 +    │
│   村庄故事 + 支书Vlog                    │
│ • 每个支柱配固定栏目名和时间节奏          │
├─────────────────────────────────────────┤
│ 第3层：运营层（GROWTH）                  │
│ • 平台：抖音（主）+ 视频号（辅）         │
│ • 节奏：每周3-5条，固定时间发布           │
│ • 互动：评论必回，私信48h内响应           │
│ • 数据：每周复盘5个核心指标              │
├─────────────────────────────────────────┤
│ 第4层：转化层（MONETIZATION）            │
│ • 信任→关注→铁粉→村民办事/农产品购买     │
├─────────────────────────────────────────┤
│ 第5层：风险层（COMPLIANCE）             │
│ • 内容边界：什么能拍什么不能拍            │
│ • 舆情预案：负面评论怎么处理             │
│ • 上级沟通：乡镇领导是否知情支持          │
└─────────────────────────────────────────┘
```

**启动时间线：**

| 阶段 | 时间 | 任务 |
|------|------|------|
| 调研期 | 第1周 | 盘村资源→定人设→找对标→选平台→注册 |
| 筹备期 | 第2周 | 写框架→备设备→试拍3-5条→审片→调整 |
| 冷启动 | 第3-4周 | 每天1条→记录数据→找爆款因子 |
| 增长期 | 第2-3月 | 加大产出→尝试直播→建立矩阵 |
| 稳定期 | 第4月+ | 固定栏目→商务/政务合作→持续迭代 |

## 五、脚本写作框架

### 通用结构（30-90秒）

```
【黄金7秒钩子】（0-7秒）
  冲突/悬念/反常识/痛点问题

【核心内容】（7-60秒）
  三段式：是什么 → 为什么 → 怎么办
       或：问题 → 过程 → 结果  
       或：过去 → 现在 → 未来

【互动收尾】（最后5秒）
  提问引导评论 / 下集预告
```

### 栏目化模板

**模板A — 工作日记类（支书日记）**
- 格式：0-5s 打招呼+关键词 → 5-10s 悬念 → 10-60s 跟拍过程 → 60-75s 结果 → 75-90s 总结+互动
- 时长：60-90秒

**模板B — 政策解读类（王支书跟你说）**
- 格式：0-5s 痛点问题 → 5-10s 引出 → 10-50s 政策逐条拆解 → 50-60s 引导互动
- 时长：30-60秒

**模板C — 村庄故事类（屯军营密码）**
- 格式：0-7s 悬念/视觉冲击 → 7-15s 引出主题 → 15-75s 叙事（访谈+空镜+史料） → 75-90s 总结升华
- 时长：60-90秒

### 脚本1：我是王健，屯军营的村支书

| 项目 | 内容 |
|------|------|
| **时长** | 45秒 |
| **栏目** | 置顶自我介绍 |
| **拍摄地** | 村委会门口 → 村口大路 → 田间 |
| **拍摄预估** | 30分钟 |

| 时间 | 画面 | 台词/字幕 | 备注 |
|------|------|----------|------|
| 0-3s | 王健从村委会走出来，对着镜头笑 | "大家好，我是王健。" | 手机稳定器跟拍后退 |
| 3-10s | 镜头转，拍村口牌坊"屯军营村" | "这里是延庆区屯军营村，我是这儿的村支书。" | 念村名时给牌坊特写 |
| 10-20s | 王健走在村路上，村民路过打招呼 | "当村支书，就是每天跟大伙儿在一起。" | 自然互动，不要摆拍 |
| 20-35s | 快速剪辑：开会/看田地/跟老人聊天/写材料（各2-3秒） | "有时候是开会，有时候是下地，有时候就是坐在村口听大爷大妈唠嗑。" | BGM轻快乡村风 |
| 35-45s | 王健站定，正面特写 | "以后我会在这儿分享屯军营的故事，喜欢就关注我，咱们一起见证这个村子越来越好。" | 字幕加粗"关注我" |

| 5-12s | 王健站在村口老树或老建筑前 | "北京延庆，有个村子叫屯军营。你有没有想过，为什么叫这个名？" | 设悬念 |
| 12-25s | 插入老地图/史料图片，或翻老物件 | "明朝那会儿，延庆是长城防线，这儿就是驻军屯田的地方。'屯军'就是驻扎军队，'营'就是军营。" | 字幕标注关键历史信息 |

| 55-60s | 王健对着镜头 | "你们村的名字也有故事吗？评论区聊聊。" | 互动引导 |

**道具：** 老照片/老物件（提前找村民借）、凳子两把
